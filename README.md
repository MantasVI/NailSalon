
# Nails By Kyu Website

A responsive business website designed for a nail artist to showcase services, display nail designs, and accept custom press-on nail orders.

## Features

* Responsive design for desktop and mobile devices
* Mobile-friendly navigation menu
* About section introducing the nail artist and services
* Press-On Nails ordering section
* Nail Expo showcase/gallery
* Instagram integration for customer contact
* Custom order form with validation
* Image upload functionality using Cloudinary
* Form submission handling through Formspree
* Modern UI with smooth navigation and visual galleries

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Cloudinary API
* Formspree
